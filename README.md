A tiny deterministic program that writes the office printer's comeback to the jams, the error codes and the thumps to `/output/entry.txt` for make.fun's "The Printer Finally Answers" bounty. Entry by @oxcaleeev; GitHub owner viseweb3.

Bounty: https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907

## Run it

```sh
node main.ts
```

This writes the printer's comeback (174 characters, one line) to `/output/entry.txt`.
